## **🚶‍♂️ Walking Help App “스몸비(Smartphone + Zombie) 사고를 막기 위한 AI 기반 보행 보조 어플리케이션”**

주변 사물을 인식하고 위험을 감지하여 사용자와 보호자에게 알림을 제공하는 스마트 보행 안전 도우미 앱입니다.

# 🧠 프로젝트 개요 현대 사회에서 스마트폰에 몰입해 걷는 '스몸비'로 인해 다양한 안전사고가 발생하고 있습니다. 이 프로젝트는 AI 기반 영상 인식 기술을 활용하여 보행 중 위험을 실시간 감지하고, 사용자와 보호자에게 즉각적으로 알림을 전달하여 사고를 예방하는 것을 목표로 합니다.

# 🔍 주요 기능

기능 설명 📷 실시간 객체 감지 전면 카메라를 통해 보행 중 앞의 사물을 인식 📱 백그라운드 감시 사용자가 화면을 보지 않아도 백그라운드에서 작동 🔔 위험 감지 시 알림 위험이 감지되면 알림음과 화면 경고 🗺️ 위치 추적 기능 현재 위치를 지도 상에 표시 📩 사고 시 보호자 연락 지정된 보호자에게 문자로 사고 알림 전송 ⚙️ 환경 설정 기능 위험 기준, 보호자 연락처 등 사용자 맞춤 설정 가능 🛠️ 사용 기술 AI 모델링: 영상 인식을 통한 객체 감지 모델 (TensorFlow, OpenCV 등)

모바일 앱 개발: Android 기반 프론트엔드 (Kotlin / Java)

서버 및 통신: Firebase 또는 기타 메시징 서비스

위치 서비스: kakao API

🧠 이찬규 (AI 개발)

💻 방명규 (프론트엔드 개발)

💻 유창현 (프론트엔드 개발)

🎯 기대 효과 보행 중 사고 예방 실시간 감지로 위험 요소를 조기에 인식하여 사고를 미연에 방지

즉각적인 대응 가능 알림과 자동 연락 기능으로 빠른 대처 가능

사회적 확장성 시각·청각 장애인을 위한 보조 시스템으로 확장 가능

다양한 산업으로의 적용 누적 데이터를 활용해 산업 안전 등 다양한 분야에 활용 가능
